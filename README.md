# MessMind AI — Antigravity Build Specification

This package contains the complete specification for building MessMind AI with:

- React frontend
- Django + Django REST Framework backend
- PostgreSQL
- AI analysis
- voice, image and video feedback
- student community
- manager analytics
- admin controls
- RBAC
- audit logging

## Critical Instruction

Correctness, reliability, data integrity, security, and edge-case handling are P0 requirements.

Read `docs/00_MASTER_INSTRUCTIONS.md` first.

Then read every document in `docs/`.

Do not implement the entire project in one uncontrolled generation step. Follow `08_IMPLEMENTATION_PLAN.md`.

The final application must pass `09_ACCEPTANCE_CRITERIA.md`.
